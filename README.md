# Bluetooth RC Car - Embedded Systems

Final project for the **Embedded Systems** course – a Bluetooth-controlled RC car.

## Authors
- **Maurycy Piasek** (hardware & code)
- **Wojciech Sztuka** (code)
- **Sebastian Dałek** (code)

## Project Overview
An Arduino-based RC car controlled via Bluetooth. The project allows wireless movement commands (forward, backward, turns) to be sent from a mobile device or computer.
